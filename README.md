# Twin Transition: Sectoral Digitalization and Carbon Intensity in the EU

> **Graduation Thesis Project**
>
> *"Modelling the Effect of Sectoral Digitalization on Carbon Intensity in the European Union's
> Twin Transition Using Hybrid Machine Learning and Explainable AI (SHAP)"*

---

## Overview

This project analyses the **non-linear relationship between sectoral digitalization and
greenhouse-gas (GHG) emissions** across **28 countries** (27 EU member states + Turkey)
using a **panel dataset** of annual observations for **2014–2023** at the **NACE Rev. 2
sector level** (Manufacturing, Construction, Trade, Logistics, ICT).

### Key objectives
* Prove that the digitalization–emissions relationship is **non-linear**.
* Beat traditional econometric models (Linear Regression) with ML achieving **R² ≥ 0.90**.
* Use **SHAP (Explainable AI)** to answer the policy question:
  *"Which digital technology investment reduces carbon the most?"*

## Methodology

```
Eurostat API ──┐
               ├──► Merge & Interpolate ──► MinMaxScaler ──► ML Training ──► SHAP
World Bank API ┘
```

### Machine Learning Architecture

| Model | Role |
|---|---|
| **Linear Regression** | Baseline / traditional econometric |
| **Random Forest** | Non-linear base learner |
| **XGBoost** | Gradient-boosted base learner |
| **Stacking Regressor** | Final model (XGB + RF → MLPRegressor meta-learner) |

All models are evaluated with **5-fold cross-validation** (R², RMSE, MAE).

## Usage

### Run with live data (requires internet + Eurostat / World Bank API access)

```bash
python main.py
```

### Re-use previously fetched data from cache

```bash
python main.py --use-cache
```

### Run with synthetic demo data (no internet required — great for testing)

```bash
python main.py --demo
```

### Run tests

```bash
pytest tests/ -v
```
